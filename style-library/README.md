# 产品风格参考库

这是面向用户的只读风格图库，独立于各工作区的个人素材。当前只交付图库代码，不生成或预填图片。界面显示真实空状态；不会使用用户的私有素材冒充官方参考图。

将已取得使用授权的 PNG/JPEG 图片放入本目录（建议 `images/` 子目录），在 `catalog.json` 的 `items` 中登记后，刷新图库即可上架，无需重新构建。不存在、越界、损坏或大于 10 MB 的图片不会出现在选择窗口。

每条配置示例（替换为真实文件，不是已提供的图片）：

```json
{
  "id": "education-clean-card",
  "title": "清晰分栏的知识卡片",
  "category": "education",
  "tags": ["知识卡片", "留白", "清晰层级"],
  "credit": "作者／授权来源说明",
  "file": "images/education-clean-card.jpg"
}
```

分类 ID：`lifestyle` 生活方式、`fashion` 穿搭美妆、`food` 美食餐饮、`travel` 旅行户外、`home` 家居设计、`education` 教育知识、`technology` 科技数码、`wellness` 健康运动、`business` 商业产品、`art` 艺术文化。

ID 使用小写英文、数字、下划线或短横线，最多 80 字符，不得重复。图片路径必须在本目录内，不支持远程图片或指向目录外的链接。用户选择后，新建方案会将参考图保存为项目内的独立快照；后续替换或下架官方图片不会影响已有方案。快照不进入生成素材库，也不会自动加入发布素材；随所属项目按现有规则清理。

素材库位于仿写项目内，通过 `/api/v1/media-library?platform=...&rewrite_id=...` 自动索引该项目的图片仿写结果、视频中生成的配图及视频成片，保留历史版本，按工作区与项目隔离。它引用现有本地文件，不复制数据；来源项目删除后遵循现有级联与引用保留规则。
