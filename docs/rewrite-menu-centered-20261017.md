# 仿写项目菜单与编辑区留白

项目列表将重命名和删除收进“…”菜单，置顶按钮保留在菜单右侧。重命名使用对话框，支持回车、取消、名称校验、失败保留输入及重试；操作其他项目不会切换当前项目或重置未保存文案。删除仍走原有确认流程与任务状态限制。

删除编辑区顶部的项目名称和“我的仿写内容”两行，将确认状态、未保存状态和刷新按钮对齐到标签栏右侧。手机宽度下操作按钮独立右对齐，为标签切换保留宽度。

文案、图片、视频编辑内容采用同一居中容器，最大宽度 840px，宽屏两侧内留白 32px、中等窗口 16px，手机沿用外层留白。文案底部保存区及图片、视频固定操作栏与内容列对齐。素材库和发布素材保持原有布局。

前端 29 项单元测试、生产构建通过。25 个相关界面用例最终通过，涵盖项目菜单、名称校验和失败重试、未保存内容保护、置顶、删除、来源项目跳转、素材选择上传、生成锁定和底部操作栏。首次检查发现手机宽度下视频标签切换受压缩影响，修复后 4 项窄屏用例复测通过。使用模拟接口验证，没有操作实际项目记录。
