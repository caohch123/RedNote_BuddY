# 仿写项目置顶与列表操作图标

每个项目右侧提供置顶、删除两个 24px 图标按钮，纵向排列，保留项目名称的展示宽度。置顶图标默认灰色，置顶后显示蓝色实心图标；再次点击取消置顶。删除图标默认灰白色，悬停或键盘聚焦时显示红色。

置顶状态使用 `Rewrite.pinned` 持久保存。`PATCH /rewrites/:id` 支持单独提交 `{pinned:true}` 或 `{pinned:false}`，兼容原有重命名请求。列表置顶项目优先，各组内按内容更新时间降序。置顶不修改内容更新时间，取消后恢复普通排序，也不切换正在编辑的项目。

前端限制同一项目重复提交，保存成功后显示新状态；旧轮询响应不会立即覆盖刚保存的选择。失败保留原状态并提示重试。删除继续使用原有确认流程。
