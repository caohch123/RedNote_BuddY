# 视频仿写V2实现与模拟验收

日期：2026-10-14。

已实现两个工作区统一的内嵌三阶段工作台、原视频自动初始化、可选参考视频和图片、独立参考用途、补充要求、可编辑时间段脚本、单次原生有声生成、结果采用及不可变历史。旧图片配音项目保留原有入口。

## 验证结果

- 全量 `go test ./... -count=1` 通过：app 45.735s、providers 3.612s、store 1.829s。
- 后续新增／修改的初始化、恢复、任务索引清理、方案排序及素材库回归通过。前端16项单元测试通过，TypeScript和生产构建通过。
- 模拟真实FFmpeg素材覆盖原视频与图片组合、纯文字、无声输入、HEVC原片转H.264播放副本，确认保留音轨、尺寸和原始文件。
- 实际请求校验脚本编辑、顺序、分辨率、比例、时长、原生声音与参考任务类型；点击编排不会生成视频；同请求ID不会重投。
- 链接与本地文件哈希不一致会在付费POST前停止；本地网络地址与非HTTPS链接拒绝；跨工作区／项目素材拒绝。
- 下载失败持久化任务ID与结果地址；恢复、重启及清理失败任务索引后继续恢复均不新建供应商任务。未知提交必须核实，普通再次生成及未确认重试拒绝。
- 采用只替换主视频或在无主视频时追加；文案、其他素材、顺序及取消勾选保持；编辑下一次要求不改变历史。引用保护覆盖输入、结果及兼容副本，素材库删除不删除历史文件。
- 增补多视频方案顺序回归：初始化与详情查询均按原素材位置排序，移除主视频、修改更新时间后不改编号；手动方案排在原视频方案后，旧制作项目仍保留。

## 验证范围

模型响应与视频地址使用本地模拟服务，公网下载以私有测试替身提供，生产下载仍校验HTTPS、DNS公网目标及文件一致性。FFmpeg／FFprobe用于实际视频格式、音轨和兼容副本验证。未调用真实文本、视觉、ASR或视频生成供应商。

按用户要求暂不运行Edge测试。真实模型权限及最终画面、运动、声音质量尚待用户审阅具体脚本后进行少量真实验收；模拟通过不代表图片或视频质量已合格。

说明与接口见 [视频仿写V2](video-rewrite-v2.md)。
