# 素材库、搜索与发布边界修复（2026-10-12）

## 问题与结果

1. 发布素材列表此前直接使用项目所有图片，包括尚未采用的生成结果及参考上传。现在候选仅包含原笔记素材、已保存版本曾显式选择的素材、当前草稿显式选择的素材。生成只入库；采用只替换主图；从库加入则追加到发布草稿。
2. 选图搜索此前包含分辨率，输入“2”会匹配所有 `896 × 1200` 图片。现在分辨率仅显示，搜索匹配名称、已有 OCR／视觉分析与官方图库标签，支持输入、回车、搜索按钮和清空。过滤不清除勾选，取消不修改方案。
3. 素材库新增加入发布素材、已加入状态与删除确认。加入后需保存版本才能确认发布；操作保留文案草稿、其他素材顺序与取消勾选。新加入或从发布区上传后取消勾选，卡片仍留在原位，方便重新选择，不会自动重新勾选。后端允许同项目视频生成配图显式加入该项目版本，仍禁止跨项目／工作区访问。
4. 版本对比入口移到文案编辑内容区，其他四个模块不显示；对比仅展示标题、正文与话题，移除独立视频模块的口播脚本；弹窗也限定在文案编辑中。

## 删除与兼容

新增 `DELETE /rewrites/:id/media-library/:asset_id`，需要 CSRF 和 `{confirm:true}`。记录 `asset.library_deleted_at`，GET 素材库与选图候选排除已删除项；重复调用幂等，失败保留卡片并可重试。

库内删除与物理文件删除分开：生成依据、历史结果、已保存发布稿和当前已选草稿可能仍引用同一文件，因此本操作不销毁这些引用或文件。物理删除仍遵守原有引用保护，删除项目时沿用原有级联清理。来源笔记素材、其他项目、其他工作区和官方参考快照不能通过这个接口删除。

旧素材无需迁移，新增字段缺失即视为未删除。新上传文件保存原始文件名供搜索；旧数据继续使用图片编号、已有 OCR 和分析。没有调用模型补齐搜索信息，也没有填充官方图库。
