# 单主图自动测试与预览溢出修复

日期：2026-10-11。承接 [图片工作流 V2](image-workflow-v2.md) 与 [此前测试记录](image-workflow-v2-test-record-20261011.md)。

## 问题与修复

1. 主图溢出：Ant Design 的默认 `height:auto` 优先级超过原预览样式，导致 150px 高度的容器内出现约 406px 高度的图片。使用组件语义样式显式指定图片宽高及 `object-fit:contain`，预览包装层限制边界。同步覆盖辅助图、历史输入图、结果图及依据缩略图，不裁切原图。
2. 单主图提示词保存：真实数据将空辅助图列表省略，前端保存发送 `[]`；后端误将其视为图片来源变更，清除提示词有效标记并丢弃手动修改。新增持久化往返测试，规范比较实际图片顺序与非空特征来源，保证空列表表示差异不会使提示词失效。
3. 原有布局测试使用 1px 测试图片，未暴露固有尺寸导致的溢出。测试素材现改为真实尺寸 PNG，新增方图、横图、竖图与图片边界断言。
