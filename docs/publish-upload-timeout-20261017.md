# 视频发布上传失败排查

发布稿《复仇者联盟5：毁灭之日》包含 MP4 视频 87,482,975 字节（约 83.43 MiB）、442 秒、1280×720，以及 JPEG 封面 361,396 字节。失败发生在笔记提交前。

账号有效，视频和图片上传许可均返回 HTTP 200、code 0。视频及封面本地解码、元数据提取、上传签名计算通过。真实上传复现时，原固定 15 秒超时返回 curl 28 / Timeout：15.002 秒仅上传 19,266,586 字节（约 18.37 MiB），仍有大部分内容没有传完。页面只保留通用的素材上传失败提示，因此容易误判为网络不可用。

修复在自有发布适配器 `publisher/bridge.py` 中对媒体 PUT 设置独立超时。连接等待仍为 15 秒；传输等待按文件大小预算，最短 60 秒、最长 900 秒。该视频的传输预算为 364 秒。许可查询、账号校验、最终创建笔记的超时及一次提交约束均保持原有行为；不修改第三方源码。

修复后用同一素材验证：视频 HTTP 200，39.52 秒上传全部 87,482,975 字节，并返回视频 ID；封面 HTTP 200，0.65 秒上传完成。验证仅运行素材上传，最终笔记提交方法被禁用，未创建或发布笔记，原稿仍保留供用户重新预览、确认。

17 项发布组件测试通过，新增大小预算、上下限和 PUT/GET/POST 隔离检查，原第三方源码校验通过。工作台重新加载后生效。排查脚本只在内存读取本机已有登录状态，记录中不包含 Cookie、上传令牌、签名或原始异常文本。
