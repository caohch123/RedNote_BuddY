# 平台标识与发布素材展示调整

- 采集列表及详情中的小红书来源标识统一为参考图的红底、白色粗字、胶囊轮廓；根据最新反馈缩至高度24px、最小宽度56px、字体15px。
- 发布素材的勾选放在卡片底部右侧，使用白底灰边圆形和深色对勾，保留原生复选框的键盘操作、选中状态和禁用行为。
- 发布素材按与素材库一致的瀑布流布局展示，图片与视频保留原始比例和完整画面。使用右上角圆形拖拽图标和右下角圆形勾选，不显示序号徽标或菜单。
- 初始沿用当前版本已保存的素材顺序，其余候选按来源顺序追加；上传素材追加。已选卡片和右上角图标均可拖拽，图标也支持Alt加方向键调整。只有选中素材参与发布排序，未选候选保留原位；勾选切换不会移动卡片。外部拖入和拖到未选卡片均不会改变勾选状态。
- 选中和未选卡片均保持白色，以右侧圆形勾选表示状态；拖拽目标使用灰色描边反馈。
- 移除误设在卡片title属性上的重复操作说明，卡片直接展示素材预览与底部勾选；拖拽和键盘排序能力保留。
- 排序写入当前文案草稿的asset_ids，保存新版本后发布稿沿用该顺序，文案、历史版本及已创建发布快照不变，也不自动采用或加入未选生成结果。后端接口沿用现有流程。
- 浏览器用例覆盖两工作区拖拽后保存及发布快照、窄窗口中性样式、右侧勾选、无序号和键盘操作；按既有要求未执行Edge测试。
