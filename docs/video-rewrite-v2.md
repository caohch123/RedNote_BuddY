# 视频仿写 V2

两个工作区使用相同的 `video_rewrite_v2` 流程：素材与要求 → 审阅提示词 → 生成并审阅视频。旧图片配音／口播编排／分镜合成流程已下线，不再展示或执行，也不迁移为新版。已有文件、发布稿及文件引用所需的归档记录保留。

## 素材与提示词

加入仿写库时为笔记中的视频按原顺序初始化草稿，默认显示第一条；无视频时创建空草稿。原视频方案以最初绑定来源保持编号，修改、更换主视频及刷新不会按更新时间重排；手动新建方案按创建顺序排列在后。初始化和进入页面均不分析、不编排、不生视频。尚未下载的视频保留绑定并显示等待状态，下载完成后可继续。重复初始化不重复创建，不覆盖用户选择。

每份草稿可选择一条被仿写视频、一条参考视频和一张参考图片。上传文件只保存到所属项目素材库，不自动进入发布素材。参考用途以 `purpose_sources` 保存，键为 `content` 内容结构、`subject` 主体形象、`action` 动作、`camera` 运镜节奏、`style` 视觉风格、`audio` 声音氛围；每项只有一个来源。图片只提供主体或视觉风格。主视频默认提供内容、主体和动作，辅助素材需要用户选择用途。未贡献用途的素材不进入分析和生成请求。

补充要求可留空，最多1000字；无参与素材时必须填写。补充修改对明确涉及的内容优先，其他部分继续遵循选择。默认输出10秒、720p、9:16、有声、1条；首版只接受单次生成，不裁剪或拼接。

点击生成提示词后才进行视觉分析和有声视频的音轨转写，复用有效的哈希／模型／规则缓存及人工修正。没有音轨时不要求ASR成功。编排任务内部组织连续时间段，覆盖所选总时长；审阅页只显示一个可编辑的最终提示词，不再显示画面、动作、运镜与声音的分段表单。保存后的 `prompt` 是唯一生成依据，空白与标点原样保留；提交时不从内部脚本重新派生、不再改写。内部时间段只保留为编排与历史元数据。

素材、用途、补充要求或输出设置变化使提示词过期；直接编辑最终提示词不会使其输入绑定失效。普通编辑自动保存；编排和视频生成前等待保存成功，失败保留编辑。提示词最多20000字，不静默截断；空提示词可保存草稿，但不能提交生成。视频模块不依赖未保存文案，也不覆盖文案草稿。

## 本地素材传递与模型能力

用户无需配置公网链接或自有云存储。确认生成后，任务先核对本地文件归属、实际格式／时长与已确认SHA256，再以当前视频模型获取百炼 `/api/v1/uploads?action=getPolicy&model=…` 私有上传凭证，上传实际选中的视频并获取 `oss://dashscope-instant/…` 临时地址；生成请求增加 `X-DashScope-OssResourceResolve: enable`。上传和生成使用相同模型与凭据，不转发Bearer密钥到存储地址。每份提交保存上传回执及保守有效期（47小时），恢复准备阶段可复用，过期仅重传文件。分析和编排不会上传视频；上传失败时尚未调用视频生成。旧手填链接不再参与新请求。图片继续使用Base64。百炼临时存储用于当前本地低并发场景；大规模生产部署应另选长期存储。

当前支持阿里云百炼万相3.0：模型 `wan3.0-video` 或 `wan3.0-video-prime`，输出2–30秒整数时长，480p／720p／1080p，比例16:9、4:3、1:1、3:4、9:16、21:9，默认模型原生声音。参与生成的参考视频单条1–15秒、最多100MB、MP4或MOV，帧率至少16fps、单边240–4096像素、长宽比不超过8:1；两条视频合计最多15秒，输入与输出视频时长合计最多30秒。超限需更换素材或调低输出时长，不自动裁剪；未选择用途的素材不计入模型限制和请求。

参考图片支持JPEG／PNG／WebP／BMP，最多20MB、单边240–8000像素、长宽比不超过8:1；PNG必须不透明。超过视觉分析接口大小限制时仅制作分析缩略副本，实际生成仍使用原图及原始哈希。

原生请求为 `POST /api/v1/services/aigc/video-generation/video-synthesis`，带 `X-DashScope-Async: enable`。提示词位于 `input.prompt`，参考素材位于有序 `input.media`，使用 `reference_video`／`reference_image`；图与视频分别按“图1”“视频1”编号。输出设置位于 `parameters`，分辨率转为大写 `720P` 等，声音使用 `audio`，显式关闭 `prompt_extend` 和水印。纯文字请求不传media。返回 `output.task_id` 后持久化，使用 `GET /api/v1/tasks/{id}` 查询；UNKNOWN／过期任务不自动重投。

技术依据：[万相3.0接口说明](https://help.aliyun.com/zh/model-studio/wan3-video-generation-api-reference)、[临时上传说明](https://help.aliyun.com/zh/model-studio/get-temporary-file-url/)、[异步任务管理](https://help.aliyun.com/zh/model-studio/manage-asynchronous-tasks)。模型、原生Endpoint URL与API Key需属于同一地域。配置完整不能代表模型权限已开通。

## 接口

统一前缀 `/api/v1`，沿用工作区参数和写操作CSRF。

| 接口 | 行为 |
| --- | --- |
| POST `/rewrites/:id/videos/initialize` | 幂等补齐视频草稿，返回 `VideoProject[]`，不调用模型 |
| GET `/video-capabilities` | 配置状态、provider=bailian_wan3、支持模型、规则版本2、时长／比例／分辨率与参考限制，不含密钥 |
| POST `/video-projects` | 新版传 `{workflow:"video_rewrite_v2",rewrite_id,version_id,primary_asset_id?}`；省略workflow或使用旧workflow返回410 |
| PATCH `/video-projects/:id` | `{revision,video_rewrite:{primary_asset_id,reference_video_id,reference_image_id,purpose_sources,requirements,output,prompt?}}`；普通草稿及最终提示词保存；旧video_urls字段忽略 |
| POST `/video-projects/:id/compose-script` | `{revision}`；持久化分析与提示词编排任务（路径保留兼容），返回任务ID |
| POST `/video-projects/:id/generate` | 新版 `{revision,request_id,prompt}`；绑定用户已审阅依据，重复请求ID去重 |
| POST `/video-projects/:id/resume` | `{action:"restore"或"retry"或"cancel",confirm_no_result?}`；已知任务只恢复查询和下载，未知提交需先核实 |
| POST `/video-projects/:id/apply` | `{asset_id,version_id}`；仅替换主视频发布位置，无主视频则追加，保留其他素材和文案 |

新增状态保存在 `VideoProject.video_rewrite`，包括素材ID、用途、输出设置、分析、最终提示词及其输入摘要、提交记录及结果。`VideoSubmission.reference_uploads` 按素材ID保存临时上传回执，绑定该提交不可变的模型和哈希；不保存上传凭证。历史 `video_urls` 保留查询兼容，新快照只用其键标记视频类型与编号，值为空。每次提交记录独立快照：输入哈希、顺序、用途、补充要求、输出设置、脚本、实际提示词、模型及修订。历史不能按当前草稿重新推断。

## 结果与恢复

只有点击生成视频才调用视频供应商；独立TTS、旧分镜与本地合成执行器已移除。成功原片自动进入本项目素材库，默认未采用；可下载、审阅并查看历史依据。必要时创建同尺寸的H.264播放副本，保留原始文件和声音，不重复生视频。

点击采用后仅调整对应发布素材，保留其他素材顺序、文案及用户未勾选状态；也可从素材库明确加入发布素材。生成完成本身不会改变发布选择。

付费提交前持久化边界，供应商任务ID及结果地址返回后先保存，再查询／下载。页面关闭或服务重启可恢复已有任务。提交结果不明不自动重投；已知任务查询或下载失败不新建任务。有效但尺寸或时长异常的结果保留并提示，不自动重画。

引用保护覆盖当前素材、提交快照、历史结果、预览副本、发布版本和任务。素材库删除仅移除库内展示；物理删除仍受引用保护。项目和工作区边界贯穿上传、选择、分析、生成、采用及删除。

## 验证约定

先使用模拟服务验证初始化、脚本编排、请求一致性、去重、失败及重启恢复、采用和隔离行为；前端执行单元测试与生产构建。本轮按用户要求暂不运行Edge。真实生视频须先由用户审阅具体脚本和输出参数，再明确提交一条短视频；接口成功不能替代画面、运动、声音和参考效果的人工验收。

## 旧流程下线

旧创建／查询／修改／生成分支返回410，plan和render路由删除，旧任务不能入队或重试。服务启动时取消尚未执行完成的旧任务，提交结果不明的记录保留待核实状态、任务ID和已返回素材，不触发供应商调用。素材库读取旧产物和删除引用保护仅用于保留已有文件，不恢复旧制作能力。配音配置、渲染路径、安装与依赖检查已移除。

## 视频供应商替换兼容

新脚本保存规则版本2，输入摘要和生成快照绑定 `provider=bailian_wan3`。原脚本与历史结果不改写，但需要重新编排和审阅后才能提交百炼。识别旧视频配置时仅复用已知百炼工作空间地址，不复制其他能力密钥，也不向新供应商发送旧密钥。

已保存的原任务ID不能转移到百炼；旧任务不会自动轮询或重投，允许核实后取消。已保存结果URL可继续下载，已有素材和发布稿继续保留。成功结果保存真实宽高、时长和音轨；分辨率以任务返回的SR档位核对，不继续套用原供应商固定尺寸表，异常有效文件保留并提示。
