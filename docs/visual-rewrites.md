# 图片与视频仿写

2026-10-14：两个工作区的新视频仿写入口已升级为“素材与要求 → 审阅脚本 → 生成并审阅动态视频”。默认绑定笔记原视频，支持一条参考视频、一张参考图片和补充要求；原图片配音、口播编排及本地合成流程已移除。当前流程、手动公网链接、模型限制及恢复行为详见 [视频仿写V2](video-rewrite-v2.md)。

文案、图片和视频分别操作，视频使用独立素材与要求，图片和视频操作不会覆盖未保存文案或其他发布素材。

## 图片仿写 V2

图片流程为“选图与特征 → 审阅提示词 → 生成并审阅”。一张主图、最多两张辅助图，七项特征分别选择唯一来源；主图文字单独确认。自动保存普通修改，文本模型编排后由用户审阅，确认才调用图片模型。支持 1–4 张串行生成和部分失败恢复，结果默认进入本项目素材库，采用时仅替换主图。

旧方案与历史提示词保留，重新使用需主动确认主图并创建新版方案。详细字段、分辨率、接口及恢复规则见 [图片仿写 V2](image-workflow-v2.md)。

## 视频仿写

两个工作区统一使用素材与要求 → 审阅脚本 → 生成并审阅视频。原视频自动带入，可选一条参考视频和一张参考图片，用户选择参考用途并补充要求；脚本编排后可编辑，确认后才生成视频。结果默认进入素材库，采用后才调整发布素材。详细约定见 [视频仿写V2](video-rewrite-v2.md)。

## 服务与恢复

- 特征分析：独立 `vision`，默认 `qwen3-vl-plus`，多模态 Chat Completions 与 JSON 输出。
- 提示词和脚本编排：现有 `text`，默认 `qwen-plus`，需支持 JSON 输出。
- 参考图仿写：`image` 的 `qwen-image-3.0`／`qwen-image-3.0-pro`／`qwen-image-2.1-pro`。兼容协议使用 `/images/generations` 的 `image` 扩展；原生协议使用 `/api/v1/services/aigc/multimodal-generation/generation`。通过设置中的地址选择协议，不在失败后自动改用另一协议重复提交。

图片连接检测只查询模型列表，不证明具体模型可用。根据控制台完整 API Host 配置地址，模型、地址和密钥需属于同一地域／业务空间。[官方图片接口文档](https://help.aliyun.com/zh/model-studio/qwen-image-generation-and-editing-api-reference)提供业务空间专属地址与两种协议参数。

生成请求超时、响应不明，或服务已返回结果而本地下载／保存失败时，暂停任务并禁止自动重投。图片完整保存且绑定原任务时，重启复用结果。先核实供应商生成记录，已有结果可下载后上传到发布素材；确认没有结果后，点击「核实结果后解除暂停」再人工提交。方案任务互斥，编排不会覆盖正在生成的项目。删除仿写项目／工作区时清理关联图片结果及任务，其他版本或发布稿引用的素材按原规则保留。
