# 百炼视频生成接入与验证

视频仿写改用阿里云百炼万相3.0：`wan3.0-video`（默认）或 `wan3.0-video-prime`。工作流为素材与要求、审阅可编辑的最终提示词、确认生成、结果采用；视频本地文件由任务自动临时上传，不需要用户填写公网链接。

## 配置

在设置 → 共用AI服务 → 视频生成与仿写填写百炼视频服务原生Endpoint URL、模型及API Key。北京地址示例为 `https://{WorkspaceId}.cn-beijing.maas.aliyuncs.com/api/v1`，需将WorkspaceId替换为真实业务空间ID；其他地域以百炼控制台为准。模型、地址及密钥必须属于同一地域。不能使用兼容文本的 `/compatible-mode/v1`。

旧视频配置只迁移模型默认值和已经明确配置的百炼工作空间地址；旧供应商密钥以及其他能力的密钥不自动复制。没有百炼视频密钥时显示待配置。连接检查只查询任务列表，不生成视频，也不能证明模型调用权限。

## 关联改写

- 创建：原生 `POST /api/v1/services/aigc/video-generation/video-synthesis`，异步请求头；`input.prompt`与有序`input.media`，参考素材分类型编号“视频1”“图1”。纯文字不传media。
- 输出：`parameters.duration/resolution/ratio/audio`，分辨率显式转为大写；`prompt_extend=false`、`watermark=false`，不让供应商隐藏改写已审阅提示词。
- 查询：持久化`output.task_id`后GET原生tasks接口，识别PENDING／RUNNING／SUCCEEDED／FAILED／CANCELED／UNKNOWN；UNKNOWN或查询过期暂停，不新建付费任务。
- 时长：输出2–30秒；参考视频单条1–15秒、合计最多15秒，输入和输出视频时长合计最多30秒。前端提示和后端按真实文件检查一致，不自动裁剪；未选择用途的素材不进入模型请求或时长预算。
- 文件：视频最多100MB、MP4/MOV、至少16fps、单边240–4096像素；图片最多20MB、JPEG/PNG/WebP/BMP、单边240–8000像素，PNG不透明。长宽比均不超过8:1。超过视觉分析大小限制的图片仅制作分析副本，生成仍使用原图与哈希。
- 下载：接入百炼阿里云结果地址，校验HTTPS和供应商域名，重定向与DNS仍保持公网检查，不携带供应商密钥。真实尺寸、时长、音轨入库；以原生任务SR档位核对分辨率，不套用原供应商固定尺寸表，异常有效文件保留并提示。
- 兼容：脚本规则版本2，快照绑定`provider=bailian_wan3`。原脚本需重新编排，原供应商任务不迁移、不向百炼重投；已有结果URL可恢复下载，历史文件和发布稿保留。旧排队脚本不会在供应商切换后自动调用模型。
