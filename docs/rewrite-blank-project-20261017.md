# 空白项目入口与文案设置布局

仿写库搜索框右侧增加方框铅笔图标，点击创建并选中一个独立的空白项目。搜索词会清空；请求失败时保留当前项目和未保存的编辑，按钮可再次重试。

空白项目没有来源笔记，也不在采集库创建占位记录。初始文案标题、正文、话题、口播、发布素材均为空；图片和视频方案各保留一个空方案，主素材、辅助参考、提示词、分析和生成结果均为空。创建过程不会调用模型或产生后台任务。用户可随后上传素材、保存和确认文案、准备发布稿，也可填写补充要求生成文案。

后端创建接口沿用 `POST /api/v1/rewrites?platform=xiaohongshu`，请求为 `{"blank":true}`。空白记录保存 `blank` 标识和空 `note_id`，与来源笔记项目的两份上限分开计算。已有来源项目保持原行为；所有写入继续校验工作区和 CSRF。

文案的目标读者、表达语气、正文长度改为三列同一行，列间距 16px，保留标签和原有编辑区域留白。
