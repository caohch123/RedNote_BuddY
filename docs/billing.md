# 计费面板

侧栏设置按钮上方的“计费面板”用于查看本工作台的模型调用用量。界面沿用工作台的浅色布局，支持今天、近 7 天、近 30 天和全部记录，以及模型、调用类型筛选。

## 统计口径

- 从启用此功能的时间开始记录；旧响应没有保存用量，历史 Token 不补算，也不按文字长度推测。
- 文案生成、提示词编排、视觉分析和 OCR 从实际模型响应的 `usage` 提取输入、输出和总 Token。仅返回输入与输出时，总量为两者之和。
- 缓存 Token 属于输入 Token，推理 Token 属于输出 Token，不能再次加到总量中。缺失字段保留为空，界面显示“—”或“未返回明细”；服务明确返回的 0 保留为 0。
- 图片和视频接口返回的 `image_count`、`output_video_duration` 单独展示为张数与秒数，不转换成 Token。音频转写会记录调用，但当前不推算其服务端用量或费用。
- 视频任务提交与后续成功、失败结果使用同一条记录；轮询、媒体下载、连接检测和采集请求不增加模型调用次数。没有发起模型请求的配置或素材校验失败不计入调用。
- “接口成功”表示模型服务已返回有效的成功响应，本地结果处理仍可能失败。接口失败和结果待核验的记录也保留；未返回用量不等于免费。
- 统计时间根据浏览器时区分组，筛选区间的开始时间包含在内，结束时间不包含在内。

趋势图展示输入、输出与服务未拆分的总量；用量分布可在模型与功能之间切换。调用明细可以展开查看缓存、推理、媒体计量、服务来源、匿名凭据标识和任务编号，并导出当前筛选结果的 CSV。

## 单价与费用估算

单价设置按“服务来源 + 模型”保存，单位为人民币元 / 百万 Token。输入与输出单价必须显式填写，免费单价可填写 0；缓存输入单价可选。

不设置缓存单价时，输入全部按普通输入单价估算。设置缓存单价时，缓存输入按该单价估算，其余输入按普通输入单价估算；若服务未返回缓存拆分，则该调用不显示费用估算。推理已包含在输出中，不额外计费。

每条调用保留当时的单价快照。修改或移除单价只影响后续调用，历史金额不会重新计算。没有单价、没有完整输入/输出用量，以及按张或时长计量的调用不计入已估算金额，界面显示“未估算”。汇总金额同时显示覆盖了多少次调用，实际账单应以服务商为准。

## 数据保存

用量存储在原有数据库新增的 `usage_events` 表中，带有时间和模型索引，独立于项目及任务历史；删除任务历史不会清除已产生的用量。记录仅包含用量数值、模型、调用分类及必要的关联标识，不保存提示词、响应正文、API Key、Cookie 或带签名的结果地址。凭据标识为不可直接还原密钥的哈希摘要。

当前面板统计本工作台收到并成功保存的调用结果，不同步服务商账户账单，也不统计在其他客户端发起的调用。进程在收到响应前被强制结束时，该次用量可能缺失，应到服务商控制台核实。

## API

| 方法 | 路径 | 用途 |
| --- | --- | --- |
| GET | `/api/v1/billing` | 用量汇总、时间趋势、模型/功能分布、明细分页、当前单价与模型选项 |
| GET | `/api/v1/billing/export` | 导出全部匹配记录的 UTF-8 CSV，未知数值留空 |
| PUT | `/api/v1/billing/prices` | 保存单价规则，需要当前会话 CSRF 令牌 |

查询参数：`from`、`to` 为 RFC3339 时间；`timezone` 为 IANA 时区，默认 UTC；`model`、`capability` 用于筛选；`page` 从 1 开始，明细每页 20 条。汇总和图表覆盖整个筛选区间，导出不受明细页码限制。原有本机访问与工作区校验继续生效。
