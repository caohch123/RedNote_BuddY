## 发现和修复

1. 首次真实编排被主体完整性校验拒绝。旧校验要求整段主体原文逐字进入最终提示词，容易使对象、动作与报告附带的配色修饰绑在一起。失败响应的完整模型原文未保存，不能断言当时具体丢失或改写了哪个词。
2. 改为校验 `subject_original` 来源证据及 `subject_parts` 对象、动作短语。短语必须肯定出现在最终提示词中，去掉允许覆盖的颜色或画法修饰后仍须覆盖来源主体各分句。不会因正确来源证据存在就放行缺少人物的提示词；这些检查也不构成全面语义验证。
3. 再次编排虽通过来源检查，人工审阅仍发现“蓝发”与红白配色并存，以及两行中英文小字的生成要求。新增最终可见约束检查：跨图配色与画法必须写明最终来源，默认明确不添加文字、标志或水印。约束由文本模型写入可编辑提示词，生成阶段不会暗中拼接或改写。
4. 规则升级为 `prompt_rules_version: 4`。旧提示词保留，重新编排前禁止继续生图；历史结果及生成依据不变。修复了测试脚本在编排轮询超时后可能误用旧提示词的问题。

本轮共进行了 3 次文本编排：1 次校验失败、2 次成功。失败没有触发生图。最终审阅阶段仍将报告中附带的蓝色描述整理为统一白线画法，并按真实辅助图明确“画面右侧手抬起，画面左侧手向外下伸”，避免角色自身左右的歧义。审阅前后的完整提示词均有记录，不把经过编辑的提示词包装成无需审阅的自动编排结果。
