# 图片仿写工作流修复与验证（2026-10-11）

## 问题与调整

用户反馈图片与提示词不一致、工作流混乱。只读检查发现已有生成图属于旧方案修订，原始提示词与当前编辑内容不同；旧界面将历史图与当前编辑器并列展示，缺少原始请求回查。另一个代码缺陷是只修改风格并普通保存时可能保留旧提示词。

- 工作流明确为「选择参考图 → 确认生成要求 → 审阅结果」。已有方案默认收起新建表单，特征报告和细节配置折叠展示。
- 新增独立画面要求、图中文字；留空文字时生成要求明确不添加文字，正文只用于理解主题。
- 自动提示词使用可读段落，明确目标风格与画面要求优先于参考图，不再直接拼接 JSON 与转义正文。
- 修改要求必须更新提示词，再提交生成。只保存风格时后端同步更新未手改的提示词；要求与手写提示词同时冲突时拒绝静默保存。
- 保存成功立即采用返回的方案修订，防止旧轮询响应覆盖；生成请求携带修订与提示词，过时预览返回 409，不创建付费任务。
- 结果保存实际提示词、模型、比例和有序参考图 ID。旧图归入历史，显示原始请求且不能冒充当前方案结果选用；旧记录缺少的信息不补造。
- 旧版 JSON 提示词要求本人主动更新；页面加载不修改已有方案、不自动生成图片。
- 预览遵守当前工作区可见性；状态改用待提取特征、待生成、待审阅等文字。
