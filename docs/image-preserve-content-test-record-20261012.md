# 图片仿写精修：实现与测试记录

日期：2026-10-12。对应方案 6 的养生海报案例。目标是保留主图人物、动作、图示及布局，只改变画法与配色。

## 实现结果

- 新方案默认保留主图内容；旧方案仍是原来的自由组合方式，用户明确切换后才改变来源。
- 保留模式锁定主图主体、场景、布局、文字版式。画法、配色可直接指定，也可借用辅助图对应外观。
- 七项分析按内容、空间结构及外观分工，避免配色报告夹带发色、服饰身份，避免画法报告夹带人物或道具。
- 数字插画、蓝白是可编辑的明确目标，不再依靠从角色图片猜测用户想保留哪种颜色。
- 直接目标覆盖对应分析，未贡献有效特征的辅助图不进入编排或生图输入。来源分析明确标记，不能当作最终要求；保留模式空外观来源表示沿用主图。
- 提示词编排规则升级为 5：先生成最终目标特征，再组织编辑指令。来源映射、主图对象／动作、指定外观及已知冲突通过检查后才保存新提示词。
- 修改模式或目标使旧提示词失效；生成批次、结果保存当时的意图、有效来源及提示词。最终提示词原样提交，`prompt_extend:false`。
- 草稿保存、提交去重、部分失败暂停、未知结果核实、历史恢复、采用主图和工作区隔离机制继续沿用。

## 真实图片验收边界

本轮没有调用真实视觉、文本或图片模型，没有重新生成、采用或发布图片。模拟服务验证的是交互、校验和提交契约，不证明真实图像质量已达标。

当前病例的下一次提示词审阅应明确：以原养生海报为底图；保留普通睡衣女性、睡觉动作、时钟、拟人肝脏、植物装饰对象和原有信息布局；用统一数字插画表达，整体改为蓝白；不引入女仆、猫耳、鲸鱼服饰，也不保留旧的米色背景及绿橙配色。

有限词汇检查无法识别任意身份泄漏、所有颜色同义词或复杂语义冲突，也可能拒绝带自然肤色等例外的描述。自然肤色／头发颜色等例外、分区配色、更精细的身份保持和真实结果对比评分，仍需后续明确规则和小量真实验收。中文原文及细小排版的保真度同样需要逐图审阅。
