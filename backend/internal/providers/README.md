# External service adapters

All calls use backend-held keys and real protocols. Missing settings return `ErrNotConfigured`; no adapter creates demo output. HTTP errors expose status and an allowlist of provider error codes rather than arbitrary upstream messages, request bodies, keys or signed links.

- **Rewrite / script:** OpenAI-compatible `POST {base_url}/chat/completions`. Generic endpoints receive standard fields; Alibaba hosts additionally receive `enable_thinking=false` for structured JSON output.
- **Image features:** independent `vision`, default `qwen3-vl-plus`, with local Base64 image input and seven editable observed-feature fields. Image text is data, never instructions. `/models` connection checks do not prove paid inference access.
- **OCR:** the same compatible endpoint, with a local image encoded as an image Base64 data URI. Select `qwen3.5-ocr`. [Official OCR documentation](https://help.aliyun.com/zh/model-studio/qwen-vl-ocr) now recommends a workspace-specific base such as `https://YOUR_WORKSPACE_ID.cn-beijing.maas.aliyuncs.com/compatible-mode/v1`. Set the complete actual address in settings; setting the workspace header alone does not select this domain. The legacy `https://dashscope.aliyuncs.com/compatible-mode/v1` remains configurable but model availability depends on your account/region.
- **ASR:** [Paraformer WebSocket](https://help.aliyun.com/en/model-studio/websocket-for-paraformer-real-time-service), mono PCM signed 16-bit little-endian, 16kHz. Wait for `task-started`, stream paced binary chunks, send `finish-task`, and retain only final sentences with millisecond timestamps converted to seconds. A full `wss://YOUR_WORKSPACE_ID.cn-beijing.maas.aliyuncs.com/api-ws/v1/inference` address can be configured instead of the legacy gateway.
- **Image:** independently configured compatible `POST {base_url}/images/generations` with model, prompt, n=1 and size=1024x1536. Accepts verified Base64 image data or a public HTTPS image URL. URL downloads carry no bearer credentials and validate every redirect and DNS target; private destinations and oversized/invalid images are rejected. No default key or model is copied from another capability. Unknown paid submissions are paused rather than repeated. Connection checks only query `/models`.
  Reference rewriting supports `qwen-image-3.0` / `qwen-image-3.0-pro` / `qwen-image-2.1-pro`, 1–3 Base64 references, and 3:4 / 1:1 / 9:16 outputs. A base ending in `/api/v1` selects DashScope native multimodal generation (nested input/messages, size uses `*`); `/compatible-mode/v1` selects the flat compatible payload (size uses `x`). Both use a 600-second timeout and one POST per task, without automatic protocol fallback. Downloads failing after a successful paid response also pause for verification. See the [official generation/editing API](https://help.aliyun.com/zh/model-studio/qwen-image-generation-and-editing-api-reference).
- **Video rewrite:** Alibaba Model Studio Wan 3.0 (`wan3.0-video` / `wan3.0-video-prime`), native `POST /api/v1/services/aigc/video-generation/video-synthesis` with `X-DashScope-Async: enable`; `input.prompt` and ordered `input.media` reference inputs; explicit `parameters` and `prompt_extend=false`. Local videos are uploaded with model-bound private `/api/v1/uploads` policies only after confirmation. Multipart bytes match the analyzed hashes; the generation call uses temporary `oss://` references with `X-DashScope-OssResourceResolve: enable`. Upload receipts are persisted separately from paid task IDs, and upload errors never imply an unknown paid submission. The saved editable final prompt is sent verbatim. Pure text omits media. One paid POST only; `output.task_id` is persisted before `GET /api/v1/tasks/{id}` polling. UNKNOWN or expired IDs pause rather than resubmit. A read-only `/api/v1/tasks?page_no=1&page_size=1` connection check does not prove model permissions. See [video rewrite V2](../../docs/video-rewrite-v2.md).

Normal tests use HTTP/WebSocket fixtures and never consume personal keys. `TestVisualLiveProviderSmoke` is separately gated by `XHS_LIVE_VISUAL=1`; it reads DPAPI settings without recovering the live queue, makes at most one vision and reference-image call, and writes a sanitized report. `XHS_LIVE_VISUAL_IMAGE_ONLY=1` skips vision, and `XHS_LIVE_VISUAL_IMAGE_BASE` selects a diagnostic image endpoint in memory. Settings connection checks query model lists / WebSocket endpoints; they do not prove model access.


Native video endpoint, model and API Key must share a region/workspace. Old provider keys are not reused; old task IDs cannot be polled or retried through the new supplier. Previously saved result URLs and files remain recoverable. Official references: [Wan3 video API](https://help.aliyun.com/zh/model-studio/wan3-video-generation-api-reference), [asynchronous task management](https://help.aliyun.com/zh/model-studio/manage-asynchronous-tasks).
